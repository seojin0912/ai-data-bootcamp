## 모델 카드 v2 — {문제 이름}
- 데이터: { sklearn 내장 load_breast_cancer / 총 569건(학습 455 / 테스트 114) / 피처 30개, 타깃 비율 양성 62.7% : 악성 37.3%}

- 문제 유형: 분류 / (이진분류)

- **베이스라인: DummyClassifier(most_frequent) = 0.632**  

- **비교한 모델 4종: Dummy / Tree / RandomForest / XGBoost**

- 평가 지표 & 이유: '정확도'( Accuracy, score 함수) 사용. 

- [정확도]를 쓴 이유 : 클래스 비율이 63:37로 심하게 불균형하지 않고, 의료 진단 맥락이라 재현율(악성을 놓치지 않는 것)도 중요하지만 노트북에서는 정확도와 혼동행렬로 대략의 오류 유형만 확인한 수준

- **성능 비교표: | 모델 | 학습 점수 | 테스트 점수 | 격차 |
|---|---|---|---|
| Dummy(most_frequent) | 0.626 | 0.632 | -0.005 |
| DecisionTree | 1.000 | 0.912 | 0.088 |
| RandomForest | 1.000 | 0.947 | 0.053 |
| XGBoost | 1.000 | 0.947 | 0.053 |

- 과적합 진단: **DecisionTree(단일 트리)**가 학습-테스트 격차 0.088로 가장 큼 → 가지치기 없이 완전히 자라 훈련 데이터를 "외운" 전형적인 과적합. RandomForest·XGBoost는 여러 트리를 평균/순차보정해 격차를 0.053까지 줄임

- **선택한 모델과 근거:** RandomForest. 성능은 XGBoost와 동일(0.947)하고 AdaBoost(0.965)보다는 낮지만, (1) 튜닝 없이도 안정적으로 좋은 성능을 내고, (2) feature_importances_와 순열 중요도를 바로 뽑을 수 있어 해석력이 높으며, (3) 의료 진단처럼 "왜 그렇게 예측했는지" 설명이 필요한 도메인에서 비용 대비 해석력을 우선했음

- **피처 중요도 상위 3개와 해석: (RandomForest, 불순도 기반):**
1. worst perimeter (0.137) — 종양의 가장 큰 둘레. 종양이 클수록 악성 가능성이 높아짐
2. worst area (0.137) — 종양의 가장 큰 면적. 크기 지표라 perimeter와 거의 같은 정보를 담고 있어 중요도가 비슷하게 나타남
3. worst concave points (0.116) — 세포 경계가 안쪽으로 파인 지점의 개수. 이 값이 클수록 세포 모양이 불규칙 → 악성일 가능성이 높음
  → 종합하면 "크기가 크고 경계가 불규칙한 종양"일수록 악성으로 예측하는 경향

- **중요도의 한계 명시:**
- 방향성 부재: "커질수록 악성"인지 "커질수록 양성"인지 중요도 값 자체는 알려주지 않음 (부호가 없음)
- 개별 설명 불가: 특정 환자 1명이 왜 악성으로 분류됐는지는 전체 평균 중요도로 설명 안 됨 (SHAP 등 필요)
- 인과 아님: "worst perimeter가 중요하다"가 "종양 크기를 줄이면 악성 확률이 낮아진다"는 뜻은 아님 — 상관관계일 뿐
- 상호작용 은폐: 노트북 퀴즈에서도 나왔듯, 한 피처를 섞어도 상관된 다른 피처(worst area 등)가 정보를 대신 채워주면 순열 중요도가 실제보다 낮게 나올 수 있음

- 한계 & 다음 단계: 정확도 단일 지표로만 봤으므로 재현율(민감도)·정밀도·ROC-AUC를 추가 확인하고, SHAP으로 개별 환자 단위 설명력을 보강해야 함
