## 모델 카드 v3 — 구매 전환 예측

- 데이터: UCI Online Shoppers (12,330 세션, 수치형 10개 열만 사용)
- 문제 유형: 분류
- 베이스라인: DummyClassifier(most_frequent) = {0.8451}

---


- **검증 방식: StratifiedKFold(n_splits=5, shuffle=True, random_state=42)**
- **성능: CV 정확도 1위 XGBoost { 0.895 } ± { 0.005 }  ← (RandomForest: 0.894 ± 0.006 — 아래에서 "구별 안 됨"이라고 쓴 것처럼 통계적으로 동급)
- **분할 운의 폭: 시드 10개 홀드아웃 { 0.885 }~{ 0.900 } (폭 { 0.015 })**

- **한 번 재기(Holdout) vs 여러 번 재기(CV):**
Holdout 기준 1위: RandomForest {0.8958}
CV 기준 1위:      XGBoost {0.8946}

[Holdout]
RandomForest      0.8958
XGBoost           0.8909

[CV]
RandomForest 0.894 ± 0.006
XGBoost 0.895 ± 0.005

CV에서 RandomForest - XGBoost 의 차이는 0.001로 두 모델의 표준편차보다 작다. **둘은 구별되지 않는다**


**- 과적합 진단:** 학습 점수 {1.0} vs 검증 점수 {0.895 }, 격차 {0.105} → { 과적합 매우 심각 }
학습은 (매우) 완벽하게 됐지만 검증 점수가 0.895,
즉 처음 보는 데이터에서는 8.9%p 성능이 떨어짐. 
min_samples_leaf=1의 상태에서 잎의 개수를 늘려 과적합 문제를 해결할 수 있음.
---


- **복잡도 조정 전후: { min_samples_leaf 1->20 } 적용 시 CV {0.893}→{0.897}, 격차 {0.105}→{0.025}**

- **학습곡선 판단: 데이터 추가 { 가치 없음 } — 근거: { 검증 곡선의 오른쪽 끝이 평평하면 데이터 추가의 이득이 거의 없다는 뜻이고, 학습 곡선과 검증 곡선이 평행하게 나타남. 이미 모델이 이 열 10개로 짜낼 수 있는 것을 전부 다 짜냈다는 의미 }**
