- 데이터: UCI Online Shoppers (12,330 세션, 수치형 10개 열만 사용)
- 문제 유형: 분류
- **베이스라인: DummyClassifier(most_frequent) = {0.845}**
- **비교한 모델: Dummy / 단일 트리(기본) / 단일 트리(max_depth=5) / RandomForest / XGBoost**

---

- 평가 지표 & 이유: { '정확도'( Accuracy, score 함수) 사용. 
- [정확도]를 쓴 이유 : 이번 과제 목표가 "여러 모델을 같은 기준으로 나란히 비교"하는 것이라 계산이 단순하고 해석이 직관적인 정확도를 기본 지표로 씀. 다만 구매 전환율이 15.47%로 불균형해서, 베이스라인(무조건 다수클래스, 0.845)을 항상 같이 표에 넣어 "정확도가 높아 보여도 베이스라인보다 얼마나 나은가"를 기준으로 판단함. (재현율·정밀도 등은 아직 안 봐서 한계 항목에 남김)

- 과적합 진단: **DecisionTree(의사결정나무 / 단일 트리)**가 학습-테스트 격차 0.158로 가장 큼 → 가지치기 없이 완전히 자라 훈련 데이터를 "외운" 전형적인 과적합. 같은 트리를 max_depth=5로 제한하면 격차가 0.011로 확 줄어드는데, 테스트 정확도(0.894)는 오히려 기본 트리(0.842)보다 높음 → 나무가 너무 복잡했던 게 문제였다는 증거. 

---


- **선택한 모델과 근거: { 의사결정나무(max_depth=5) }**

1. 테스트 정확도 1위는 랜덤포레스트(0.896)지만, 의사결정나무(max_depth=5)가 0.894로 거의 차이가 없음(0.002p) 
2. 학습-테스트 격차는 0.011로 랜덤포레스트(0.104)보다 훨씨 작음
3. 성능 차이가 미미한 반면 안정성·해석력 차이는 크므로, **해석력과 일반화 안정성을 우선**해서 의사결정나무(max_depth=5)를 최종 모델로 선택. 
4. 트리 하나라 규칙을 그대로 그려서 마케팅팀에 보여줄 수 있고
5. 비용도 훨씬 저렴.

- **중요도의 한계 명시: 방향성 부재 / 개별 설명 불가 / 인과 아님**
- 방향성 부재: "커질수록 구매율 증가"인지 "감소"인지 중요도 값 자체는 알려주지 않음 (부호가 없음, 그래서 위 표처럼 직접 groupby로 확인해야 방향을 알 수 있음)
- 개별 설명 불가: 특정 세션 1건이 왜 구매로 분류됐는지는 전체 평균 중요도로 설명 안 됨 (SHAP 등 필요)
- 인과 아님: "PageValues가 중요하다"가 "PageValues를 올리면 구매가 늘어난다"는 뜻은 아님 — 상관관계일 뿐 (예: 이미 구매 의사가 있는 사람이 페이지를 더 많이 봐서 PageValues가 높아졌을 수도 있음)
- 상호작용 은폐: 상관된 다른 피처(예: ProductRelated ↔ ProductRelated_Duration)가 정보를 대신 채워주면 순열 중요도가 실제보다 낮게 나올 수 있음 (이번엔 불순도 기반만 써서 이 문제를 아직 확인 못 함)

- **한계 & 다음 단계:**
1. 불순도 기반 중요도만 사용 → 상관된 피처가 있으면 왜곡될 수 있음. **다음 단계:** 피처 중요도 해석 단계에서 `permutation_importance`로 교차 검증해서 두 결과가 크게 다른 피처가 있는지 확인.
2. 정확도 하나만으로 비교 → 구매 전환율 15.47% 불균형 상황에서 재현율/정밀도, ROC-AUC를 안 봄(마케팅팀이 실제로 궁금한 건 "구매할 사람을 얼마나 놓치는가"일 수 있음). **다음 단계:** 성능 비교표 작성 단계에서 confusion matrix·recall·precision·ROC-AUC를 추가.
3. 개별 세션 설명 불가. **다음 단계:** 모델을 실무에 적용하기 전 단계에서 SHAP 값을 도입해 특정 세션 단위 설명을 보완.
