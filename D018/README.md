## 모델 카드 v1 — 구매 전환 예측

- 데이터: UCI Online Shoppers (12,330 세션, 수치형 10개 열만 사용)

- 문제 유형: 분류

- 모델: 베이스라인(Dummy) → LogisticRegression

- 평가 지표 & 이유: {Accuracy(정확도).} 다만 Revenue 클래스 비율이 불균형(구매 비율 ≈ 15% 내외)이라 정확도 하나만으로는 "다수 클래스만 찍어도 잘 맞는" 착시가 생길 수 있음 → 그래서 베이스라인(Dummy) 정확도와 나란히 비교하는 게 핵심.

- 성능: 베이스라인 {base_acc:0.845} → 내 모델 {acc_test:0.880} / 학습 {acc_train:0.884} vs 테스트 {acc_test:0.880}

- 과적합 진단: {차이가 거의 없다(0.884-0.880=0.04) → 과적합 아님, 오히려 로지스틱 회귀는 단순한 선형 모델이라 과소적합(underfitting) 쪽에 더 가까울 수 있음.}

- 한계 & 다음 단계: { 예: 범주형 8개 열 미사용-> 원-핫 인코딩 배울 때 추가 예정, 불균형인데 정확도만 봄→ Precision/Recall/F1, Confusion Matrix, ROC-AUC는 평가지표 심화 시간에 다룰 예정, PageValues처럼 스케일이 큰 피처의 영향력을 계수로 해석하려면 추가 분석 필요}

## 모델 카드 v1 — 자전거 대여량 예측

- 데이터: UCI Bike Sharing (731일, 날씨 피처 4개)

- 문제 유형: 회귀

- 모델: 베이스라인(Dummy) → LinearRegression

- 평가 지표 & 이유: {R²(결정계수). 회귀 문제에서 "내 모델이 평균만 찍는 것보다 얼마나 더 설명력이 있는가"를 직관적으로 보여주는 지표라서 선택. (MSE도 함께 계산해뒀지만, MSE는 단위가 cnt(대여 건수) 그대로라 값 자체만 보면 크기 감이 안 옴 → R²가 비교엔 더 편함) }

- 성능: 베이스라인 {base_r2:-0.020} (정의상 ~0) → 내 모델 {r2_test: 0.499} / 학습 {r2_train:0.450} vs 테스트 {r2_test:0.499}

- 과적합 진단: {테스트 R² 0.499가 학습 R² 0.450보다 높습니다.(-0.049) 과적합의 반대 현상입니다.} - 731일이라는 작은 데이터에서 8:2로 한 번 나눴을 뿐이니, 이건 실력이 아니라 분할 운입니다. 이 흔들림을 제대로 재는 법(교차 검증)은 뒤 순서에서 배웁니다.

- 한계 & 다음 단계: {temp와 atemp는 상관관계가 매우 높은 변수(다중공선성) → 나중에 VIF나 상관행렬로 점검 필요, 요일(weekday), 공휴일(holiday), 계절(season), 연도(yr) 등 시간 관련 피처 미사용 → 다음 단계에서 추가 예정, 대여량은 시계열 데이터인데 지금은 랜덤 분할(train_test_split)을 썼음 → 시계열 특성을 고려한 분할(시간순 분리)이 더 적절할 수 있음, 추후 다룰 예정}
